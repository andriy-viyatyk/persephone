# REST Client

REST Client is a bundled board that edits and sends HTTP request collections. Open an existing
`.rest.json` file or create a standalone page from the **+** menu. The collection format remains
JSON with `"type": "rest-client"` and a `requests` array.

For request editing, collection management, scripting, and agent guidance, read the
[REST Client board guide](../installed-boards/rest-client/index.md).
